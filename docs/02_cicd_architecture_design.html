Commit Message Convention

<type>(<scope>): <subject>

Types: feat, fix, docs, style, refactor, test, chore, perf, security
Scopes: veda, playground, dashboard, webservices, ai-manager, theme, core

Examples:
feat(playground): add Python 3.12 language support
fix(veda): resolve LiveKit token expiry race condition
security(webservices): add CSRF validation to file upload endpoint
chore(ci): add PHPStan level 5 analysis step

2.6 Rollback Strategy

flowchart LR A["Smoke Test Failed?"] -->|Yes| B["Keep maintenance mode ON"] B --> C["Repoint symlink to previous release"] C --> D["Restore DB backup if schema changed"] D --> E["Purge caches"] E --> F["Disable maintenance mode"] F --> G["Verify rollback"] G --> H["Alert team via Slack/Email"]

The symlink-based deployment enables instant rollback — simply repoint the current symlink to the previous release directory. The server directory structure:

/var/www/html/moodle/
├── releases/
│   ├── 2026-05-10_v1.1.0/    ← previous
│   ├── 2026-05-15_v1.2.0/    ← current (symlinked)
│   └── 2026-05-20_v1.3.0/    ← next (being deployed)
├── current -> releases/2026-05-15_v1.2.0/  ← nginx points here
├── shared/
│   ├── config.php             ← generated from template + env vars
│   └── .htaccess
