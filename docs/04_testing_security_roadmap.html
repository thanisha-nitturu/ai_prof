⚠️ CAUTION: Do these BEFORE anything else. These are production risks.
#ActionHow
1Remove hardcoded DB passwordReplace config.php with template; use env vars
2Fix directory permissionsChange 0777 → 0750 in config template
3Remove tool_generator passwordDelete from production config entirely
4Delete debug logsRemove handler_debug.log (3MB), token_debug.log
5Delete backup filesRemove lib.php.backup, *.backup*
6Add .htaccess to Veda APIBlock direct access to log files

4.2.2 GitHub Branch Protection Rules

Branch: main
  ├── Required reviews: 2
  ├── Dismiss stale reviews: true
  ├── Required status checks: lint, phpunit, frontend, security
  ├── Enforce admins: true
  ├── Allow force pushes: false
  └── Allow deletions: false

Branch: develop
  ├── Required reviews: 1
  ├── Required status checks: lint, phpunit
  └── Allow force pushes: false
