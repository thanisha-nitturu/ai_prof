🧩 Create Quiz from XML

local_create_quiz_from_xml

Atomic 3-step operation: creates quiz → imports XML questions → populates quiz slots. Uses DB transactions & user switching. Pre-configured with 50-min timer, 3 attempts, 70% pass.

In: courseid, sectionnum, quizname, categoryname, xmlfile, userid  →  Out: {quizid, cmid, categoryid, questioncount}
WRITE

♻️ Update Quiz from XML

local_update_quiz_from_xml

Destructive update: deletes the existing quiz entirely, cleans up categories, then recreates from fresh XML. All student attempts are lost.

In: cmid, sectionnum, xmlfile, categoryname, userid, quizname?  →  Out: {status, quizid, cmid, categoryid, questioncount}
WRITE
