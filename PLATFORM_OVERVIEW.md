# Platform Overview: Dev Learn (ai.prof)

---

## 1. What is Dev Learn?

**Dev Learn** (branded as **ai.prof**) is an intelligent, AI-powered online learning platform built specifically for technology and software engineering education. It is a fully customized Learning Management System (LMS) that goes far beyond a standard online course platform.

The platform is designed to give every student a **personalized learning experience**, where an AI assistant understands each student's strengths, weaknesses, and progress, and proactively helps them succeed.

**Live URL:** [devlearn.hitloop.com](https://devlearn.hitloop.com)

---

## 2. What Does the Platform Do?

The platform provides a complete end-to-end learning journey for students pursuing software engineering, programming, and tech careers. Its key capabilities are:

### 🎓 Online Course Management
Students can enroll in structured courses that cover topics like Python programming, web development, data structures, SQL, and more. Each course contains lessons, assignments, and quizzes.

### 🤖 AI-Powered Personal Tutor (Veda)
Every student has access to **Veda**, an AI chatbot that acts as their personal tutor. Veda is not a generic chatbot — it knows exactly who the student is, what course they are enrolled in, and how they are progressing. It can answer subject-specific questions, explain concepts, and guide students through problem areas in real time.

### 💻 In-Browser Coding Practice (Coding Playground)
Students can write and run real code directly in the browser — no software installation needed. They can practice Python, Java, C++, SQL, and many other languages. The platform automatically evaluates their code against test cases and provides instant feedback.

### 📊 Performance Analytics (Course Dashboard)
Teachers and students can view detailed analytics about course performance, quiz scores, and assignment progress. Teachers can monitor all students in their class from one screen, while students can track their own individual improvement over time.

### 🏆 Placement Tracking
The platform includes a dedicated placement management dashboard for administrative staff to track student career readiness, company interests, and placement outcomes.

---

## 3. Who Uses the Platform?

The platform is designed for three types of users, each with a different experience:

### 👨‍🎓 Students
- Enroll in courses and follow structured learning paths.
- Chat with the Veda AI tutor at any time for help.
- Practice coding in the built-in IDE.
- View their own performance analytics and quiz results.
- Must have a profile picture to access the platform (for AI proctoring purposes).

### 👨‍🏫 Teachers / Instructors
- Create and manage course content (lessons, quizzes, assignments).
- View the performance of every student in their class.
- Access a detailed analytics dashboard showing which students are struggling.
- Monitor quiz attempts and grades at a granular level.

### 🛠️ Platform Administrators
- Manage all users, courses, and platform settings.
- Access the Placement Dashboard for career tracking.
- Control AI settings, quotas, and student data sync.
- Manage custom menu, navigation, and site branding.
- Have the highest level of access across all features.

## 5. What Makes This Platform Different?

Unlike a standard Moodle LMS, Dev Learn has several unique advantages:

1. **AI that Knows You:** The Veda AI tutor has access to your course history, quiz performance, and recent activity. It gives answers that are specific to *your* progress, not generic responses.

2. **No Setup Required for Coding:** Students can practice real programming in any language without installing any software. The code runs on the server in a secure environment.

3. **Role-Based Experience:** Teachers and students see completely different interfaces on the same platform. Each role sees exactly what they need, nothing more.

4. **Integrated Everything:** Chat, code, learn, and track progress — all from a single platform without switching between tools.
