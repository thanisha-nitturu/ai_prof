🔄 Request Flow
1

Write & Submit Code

Student writes code in Monaco Editor and clicks Submit. Frontend sends POST to /api/v1/submissions/

2

Fetch & Prepare

Server fetches question + test cases from MongoDB. Encodes source code & stdin in base64 batches

3

Execute on Judge0

Batch submit to Judge0 (up to 1000 cases/chunk). Retry with exponential backoff on overload

4

Sandboxed Execution

Judge0 runs code in isolate sandbox with CPU/memory limits. Returns stdout, stderr, status per case

5

Compare & Store

Server parses output, compares with expected (lenient), determines AC/WA/TLE/RE. Saves to MongoDB

6

Display Results

Frontend receives results. ConsolePane shows per-case status with input/expected/actual output
